# pi-fzf-completion

Search pi's slash-command and path autocomplete suggestions with [fzf](https://github.com/junegunn/fzf). This is entirely vibe-coded at the moment.

## Install

Install `fzf` and `fd`, then install the extension:

```sh
pi install git:github.com/bradykieffer/pi-fzf-completion
```

or

```sh
make install
```

if developing locally. Restart pi, type an `@` path or slash command, then press `Ctrl+Shift+R`.
